# Pixel Office macOS 상주 실행

사용자가 승인한 방향: 터미널에 종속되지 않는 서버를 먼저 제공하고, 기존 화면을 메뉴바 데스크톱 앱에서 연다. 창이나 앱을 닫아도 서버는 유지하며 로그인 후 다시 사용할 수 있어야 한다.

## 구조

- 사용자 LaunchAgent `io.pixeloffice.server`가 시스템 Node 24 이상으로 빌드된 서버를 실행한다. `RunAtLoad`, `KeepAlive`, 재시작 간격, 로그 경로를 설정한다.
- 설치 당시 저장소·Node·데이터 절대 경로와 필요한 CLI 검색 경로를 사용자 Application Support에 저장한다. 기존 `.pixel`과 공급자 로그인 위치를 사용한다. 임의의 환경 변수와 인증 토큰을 복사하지 않는다.
- CLI는 install/start/stop/status/open/uninstall을 제공한다. 설치/시작 시 포트 충돌을 확인하며 다른 서버를 종료하지 않는다. 연결 파일의 토큰으로 실제 인증을 확인한 뒤 준비 완료로 판단한다.
- Electron은 기존 로컬 웹 UI를 sandbox/contextIsolation 환경에 표시한다. 창 닫기는 숨김, 메뉴바 앱 종료는 화면 프로세스만 종료한다. 서버 재시작으로 연결 토큰이 바뀌면 새 연결 URL로 복구한다.
- 앱을 `~/Applications/Pixel Office.app`에 설치한다. 서버는 기존 저장소에서 실행되므로 저장소·Node 설치는 유지해야 한다. 타인 배포용 독립 설치 패키지와 코드 서명은 범위 밖이다.
- 메뉴에서 화면 열기, 브라우저 열기, 로그 보기, 로그인 시 메뉴바 앱 실행, 메뉴바 앱 종료를 제공한다.

## 한계와 검증

서버 자동 재시작은 중단된 에이전트 작업의 자동 재실행을 뜻하지 않는다. macOS 잠자기·전원 종료 중 실행은 보장하지 않는다. 앱 작업 완료와 입력 대기는 메뉴바 알림으로 전달할 수 있도록 현재 API 상태를 확인한다.

설정 직렬화·연결 검증·포트 충돌·서비스 수명주기를 테스트한다. 실제 launchd 등록, 프로세스 복구, 창 닫기 후 서버 유지, 앱 재개를 검증한다. 기존 변경은 보존한다.
