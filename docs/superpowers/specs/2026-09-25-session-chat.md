# 세션별 작업 화면과 기록 기반 대화

사용자가 승인한 방향: 레포별 화면을 유지하면서 세션마다 캐릭터를 표시한다. 읽기 쉬운 현재 작업과 작업 내역, 질문과 말풍선 답변을 제공한다.

- 오피스를 작게 만들고 선택한 세션의 요약 / 작업 내역 / 대화 패널을 제공한다.
- 세션 목록은 검색과 활동 필터를 지원한다. 각 캐릭터의 이름, 상태, 현재 작업을 구분한다.
- 채팅은 같은 공급자의 별도 요청으로 선택한 세션의 최근 기록과 해당 세션 대화만 참고한다. 기존 프로세스의 내부 추론이나 실시간 직접 답변으로 표현하지 않는다.
- 외부 작업에 직접 명령, 승인, 중단은 제공하지 않는다. 현재 어댑터도 지속 연결을 보유하지 않으므로 직접 대화 가능 여부는 모두 false다.
- 답변은 생성 중 표시, 말풍선, 전체 대화, 실패 / 취소와 재시작 복구를 지원한다.
- 로컬 SQLite에 대화를 저장한다. 동시 요청과 출력 크기를 제한한다. 인증과 Origin 검증은 기존 API 정책을 따른다.
- Node >=24, React / Fastify / SQLite와 기존 CLI 로그인을 사용한다. 새 종속성을 추가하지 않는다.
- 도구 실행이 필요한 질문은 기록만으로 확인할 수 없음을 안내한다. 원본 세션이나 작업 폴더를 수정하지 않는다.
