# 작업 중심 화면

사용자 승인: 사무실을 작게 유지하고 새 작업과 추가 지시를 한 진입점에서 시작한다. 기존 React·CSS와 실행 API를 유지한다.

1. 작업 지시 입력창 하나에 새 작업, 앱 작업 추가 요청, 선택한 외부 세션 지시를 연결한다. 대상별 초안을 분리하고 전송 성공 시에만 지운다. IME 입력 중에는 단축키를 실행하지 않는다.
2. 동료 목록을 왼쪽 열로 옮기고 선택한 작업 내역을 중앙에 넓게 표시한다. 사무실은 기본 접힘, 펼침 선택을 저장한다.
3. 선택한 세션을 옆에 고정해 두 작업을 나란히 확인한다. 추가 지시 대상은 명확히 표시한다. 새 작업·입력 포커스·세션 전환 단축키를 제공한다.
4. 기존 승인·질문·중단·문서·코드·터미널 흐름을 유지한다. 기존 설정은 접을 수 있는 작업 옵션에 배치한다.

검증: Playwright 데스크톱/모바일에서 새 작업 → 중단 → 추가 요청, 대상별 초안 유지, 오류 후 재시도, 세션 실제 지시/승인, 분할 확인, 사무실 접힘과 재접속, 가로 넘침을 확인한다. TypeScript 검사, 단위 테스트, 프로덕션 빌드를 실행한다. 실제 사용자 세션에 작업을 전송하지 않고 기존 격리 fixture를 사용한다.
