# 작업 중심 UI 검증

- 기준: HEAD `7e0e126` + 현재 작업 트리. Quick UI verification, non-authoritative (커밋·배포 검증용 아님).
- 환경: 기존 Playwright 격리 서버, fake 모델/CLI, 실제 로컬 PTY. 실제 사용자 세션에 지시하지 않음.
- 화면: Desktop Chromium 1440×1000 / DPR 1, iPhone 13 Chromium 390×664 / DPR 3.

## 확인한 흐름

- 같은 입력창에서 새 작업 시작 → 중단 → 기존 앱 작업에 추가 요청.
- 선택한 외부 세션에 실제 실행 지시 → 승인 응답 → 답변 확인, 기록 기반 질문과 전환.
- 대상별 초안 분리, 프로젝트·화면 이동 시 유지, 실패 시 보존, 전송 도중 화면을 떠나도 성공 시 해당 초안만 삭제.
- 작업 기록에서 작업을 열면 추가 요청 대상으로 전환하고 새 작업 초안은 보존.
- 사무실 접기·펼치기와 재접속 후 상태 유지, 세션 고정·분할 보기와 대상 전환.
- 코드·문서·터미널이 중앙에 열리고 입력창은 유지됨. 확대 시 목록과 상단 정보를 접고, 축소 시 복원.
- 단축키 전송, 새 작업 버튼의 입력 포커스, 한글 조합 중 전송 방지.
- 모바일 승인·질문 버튼 조작, 코드 탐색과 PTY 입력, 원래 세션 재연결, 퇴근·복원.
- 프로젝트 전환, 모델·팀 설정, 문서 변경 비교, 하네스 설정, 사용량 안내, 워크트리 정리 회귀.
